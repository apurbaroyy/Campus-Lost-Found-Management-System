Campus Lost & Found Management System

Setup:
1. Start Apache and MySQL in XAMPP.
2. Import lost_found_db.sql into phpMyAdmin.
3. Copy this folder to:
   C:\xampp\htdocs\Campus_Lost_Found_Project
4. Open:
   http://localhost/Campus_Lost_Found_Project/

Create an admin:
1. Register normally.
2. phpMyAdmin > lost_found_db > users > Edit.
3. Change role from user to admin.
4. Login again.
